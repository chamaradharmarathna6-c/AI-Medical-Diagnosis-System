# Clinical safety

This is an academic decision-support prototype. It provides an AI-generated preliminary assessment rather than a confirmed medical diagnosis. It does not replace a clinician or emergency service.

SHAP values describe how input features contributed to a model score; they do not establish that a feature caused disease. Risk levels are academic confidence-derived bands, not clinically validated thresholds. The review workflow starts as `Pending`; a qualified reviewer may mark an assessment `Reviewed`, `Approved`, or `Rejected` with notes.

Seek qualified medical help for symptoms or urgent concerns.
